# Mini-project-02
Adjustable LED dimmer using pwm ne555 
This project is an Adjustable LED Dimmer circuit using the NE555 timer IC in PWM (Pulse Width Modulation) mode. The circuit allows the brightness of an LED to be controlled by adjusting a potentiometer, which changes the duty cycle of the PWM signal produced by the NE555 timer. By increasing or decreasing the pulse width, the amount of power supplied to the LED changes, which adjusts its brightness efficiently without wasting energy.
This project is related to SDG 7 – Affordable and Clean Energy because it demonstrates energy-efficient lighting control. Using PWM for dimming helps reduce unnecessary power consumption and promotes smarter energy usage in lighting systems, which supports sustainable and clean energy practices.
